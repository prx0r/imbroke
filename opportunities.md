## Bittensor Subnet Details

### SN118 Ditto — #1 Priority

**What:** Submit agent-memory harness as Docker artifact. Validators run it. You compete on memory architecture, prompting, tool use, retrieval, agent scaffolding.

**Why #1:**
- Validators execute your artifact — no GPU needed
- 65/14/10/7/4 reward distribution (top 5 miners paid)
- QDW already has: memory bridge, context compilation, hashed handovers, session state
- 0.04 TAO per evaluation (~$8 at current price)
- Can practice locally before paying

**Leaderboard:** ~65 submissions, leading composites 0.955, 0.944, 0.918, 0.910

**QDW factory objective:** Move Ditto memory harness from baseline toward ≥0.91 composite

**Cost:** Practice free, evaluate 0.04 TAO (~$8) per paid submission

**GitHub:** https://github.com/ditto-assistant/ditto-subnet

### SN11 TrajectoryRL — #2 for Bittensor

**What:** "Open skill factory" — produce SKILL.md packs, validators run in real sandboxes, best skill wins.

**Economics:**
- 0.47% of network emissions ≈ 6.94 TAO/day miner capacity ≈ $1,400/day theoretical
- Default 50 α per submission ≈ 0.44 TAO (~$90) per submission
- Winner-take-all: 249/256 miners but only 1 earning

**Terms:** Copyright transfers to TrajectoryRL on reward-earning win

**QDW fit:** GitGoblin → QDW Ideas → cemetery → factory evolution → SKILL.md

**Strategy:** Run 500 local mutations, pay once for genuine frontier improvement

**GitHub:** https://github.com/trajectoryRL/trajectoryRL

### SN62 Ridges — #3 for Bittensor

**Economics:**

**Terms:** IP irrevocably assigned to Hidden Harvest Ventures after upload
